A small update to Helpers: free tools that help you read, write and think things through, especially with AI. Windows 10 and 11, 64-bit.

## Install

- **`Helpers-0.1.1-setup.exe`** installs for your user only. No admin rights needed. Adds a Start menu entry and, if you choose, starts with Windows.
- **`Helpers-0.1.1-win-x64.zip`** runs from any folder. Unzip it and run `Helpers.App.exe`.

The app isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

**Coming from 0.1.0?** Install this version by hand from the files above. The Update now button in 0.1.0 can't start the installer: it closes Helpers without updating. From 0.1.1 on, Update now works. Your settings and downloads are kept.

## What's changed

- **Update now works.** It downloads the new version, checks it against its published checksum, installs it quietly and starts Helpers again.
- **The installer is for your user only.** It no longer offers to install for all users, which put Helpers where updates couldn't find it.
- **Up-to-date foundations.** Avalonia 12.1.4 draws the windows, and a few small fixes came from code scanning.

This is an early version. [docs/STATUS.md](https://github.com/drhumphrey/helpers/blob/main/docs/STATUS.md) lists what's been tried and what hasn't. Problems and ideas are very welcome as [issues](https://github.com/drhumphrey/helpers/issues).
