The first public version of Helpers: free tools that help you read, write and think things through, especially with AI. Windows 10 and 11, 64-bit.

## Install

- **`Helpers-0.1.0-setup.exe`** installs for your user only. No admin rights needed. Adds a Start menu entry and, if you choose, starts with Windows.
- **`Helpers-0.1.0-win-x64.zip`** runs from any folder. Unzip it and run `Helpers.App.exe`.

The app isn't code-signed yet, so Windows may say "Windows protected your PC". Choose **More info**, then **Run anyway**.

Some parts download the first time you use them, then work offline: the voice (350 MB) on first start, the dictionary (10 MB) on the first Look up, and the local AI model (2.5 GB) only if you choose "On this PC" in Settings.

## What's in it

- **Hear it.** Select text anywhere and press Read, or Ctrl+Alt+Space. Natural British voices on your own PC, a player that highlights each sentence and word, and sensible reading of Markdown, numbers, dates and money.
- **Write it.** Compose (Ctrl+Alt+C): spelling as you type, Read back, Send to chat without pressing Enter, and Edit and Put it back for text you've selected anywhere.
- **Shape it.** Optional AI help: Check my thinking (a reader's notes, never a rewrite), Tidy and Make a request. Runs on your PC for free, or on Claude with your own key.
- **Look up a word.** Syllables, how to say it, meanings and other words for it.
- **Private.** No telemetry. The update check is off unless you switch it on.

This is an early version. [docs/STATUS.md](https://github.com/drhumphrey/helpers/blob/main/docs/STATUS.md) lists what's been tried and what hasn't. Problems and ideas are very welcome as [issues](https://github.com/drhumphrey/helpers/issues).
